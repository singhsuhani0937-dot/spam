Q1 - Write a one-paragraph explanation of what happens between typing a URL and seeing the page. When you type a URL in the browser and press Enter, the browser first checks the DNS to convert the domain name into an IP address of the server. Then it establishes a connection with that server using TCP/IP and HTTPS, and sends an HTTP request for the webpage. The server processes the request and sends back the HTML, CSS, JavaScript, and other files as a response.
