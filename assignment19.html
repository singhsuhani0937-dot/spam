Standard Meta Tags Template (For All Files)

Har file ke <head> me ye 4 tags hone hi chahiye:

  1. charset: <meta charset="UTF-8"> - Hindi / English sahi dikhe
  2. viewport: <meta name="viewport" content="width=device-width, initial-scale=1.0"> - Mobile pe sahi dikhe
  3. description: <meta name="description" content="..."> - Google search ke liye
  4. author: <meta name="author" content="Suhani">
