The CSS Box Model is a fundamental concept in CSS. Every HTML element is treated as a rectangular box. Each box consists of 4 layers from inside to outside:

1. Content: The actual content like text or image. Its size is controlled by width and height.

2. Padding: Space between Content and Border. Inner space inside border.

3. Border: A line that surrounds padding and content.

4. Margin: Space outside the border. Separates element from other elements.

Formula: Total Width = Content + Padding + Border + Margin
Example: 200 + 20+20 + 5+5 + 10+10 = 270px

box-sizing: border-box - Padding and Border included inside width, layout does not break.
