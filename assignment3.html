Terminal Navigation Practice Sheet

Basic commands to navigate in terminal:

Command What it does Example
pwd Show current directory path pwd
ls List files in current folder ls
cd folder_name Go inside a folder cd Desktop
cd .. Go back one folder cd ..
mkdir Create new folder mkdir my-project
touch Create new empty file touch index.html
clear Clear terminal screen clear

Practice Steps:

  1. Open Terminal in VS Code with Ctrl + `
  2. Type pwd and press Enter to see where you are
  3. Type ls to see files
  4. Type cd Desktop to go to Desktop
  5. Type mkdir test-folder to make a new folder
  6. Type cd .. to go back
