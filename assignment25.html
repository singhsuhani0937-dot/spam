Design Choices - Short Note

  • Font Pairing: Headings ke liye Playfair Display (Serif - elegant) aur Body ke liye Inter (Sans-serif - readable) use kiya.
  • Colour Palette: Primary #1e3a5f Navy Blue for trust, Accent #c9a86a Gold for highlight, Background #f7f5f0 Off-white for comfort.
  • CSS Variables: Saare colours aur sizes ko :root me tokens banake use kiya, jisse future me ek jagah change karne se pura site update ho jaye.
  • Consistency: Saare pages me same header, same spacing aur same card design rakha hai, taaki project professional lage.
  • Responsiveness: Grid layout use kiya hai jo mobile aur desktop dono par achha dikhta hai.
